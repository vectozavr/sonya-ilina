# Софья — репетитор по русскому языку

Сайт: **https://vectozavr.github.io/sonya-ilina/**

Одностраничный сайт на чистом HTML/CSS/JS, без сборки и зависимостей.

- `index.html` — вся страница. Отзывы задаются списком `REVIEWS` в начале скрипта.
- `photo.jpg` — фото на первом экране (4:5).
- `reviews/` — оригинальные скриншоты отзывов.
- `og.jpg` — картинка для превью ссылки в мессенджерах.
- `video/` — видео-знакомство: 16:9 для компьютера, 9:16 для телефона, и обложки к ним.

Публикуется через GitHub Pages из ветки `main`.
